Documentation

Make Orynwave your own.

Installation, customization and integration guidance for the complete academy website.

Academy guide

Start with a simple local server.

Run locally

Install Node.js, open a terminal in the project directory and run node scripts/serve.mjs . Open http://localhost:4173 . No build or package installation is needed for the website.

Customize the brand

Edit design tokens in assets/css/variables.css , page content in the HTML files, and sample dashboard data in assets/js/demo-data.js . Reusable source templates live in scripts/build.mjs .

Demo workflows

All enrollments, statuses, invoices and charts are illustrative. Browser storage holds preferences and record IDs/statuses only. Passwords, personal contact details and payment card information are never stored.

Production integration

Connect secure authentication, a database, email and a payment provider before operating a real academy. Replace sample credentials, fictitious profiles, prices, contact details and canonical URLs.

Images & dependencies

Original AI-generated swimming photographs are in assets/images. See image-inventory.json and documentation/image-credits.md. Bootstrap 5.3.3, Chart.js 4.4.8 and Lucide 0.468.0 are bundled locally with their licenses. Plus Jakarta Sans is locally hosted.

Navigation

Two homepages, ten public content pages, five standalone pages, ten member screens and twelve admin screens are included. Read README.md for the full sitemap and verification instructions.
