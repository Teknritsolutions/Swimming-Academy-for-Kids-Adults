# Original image credits

All 46 photographic assets were generated specifically for this project with the built-in OpenAI image-generation tool. No third-party stock photographs were downloaded. Subjects are fictional. The photos are illustrative AI-generated imagery, not evidence of a real academy, actual instructors, members, or facilities.

Final assets are saved in `assets/images/` as optimized WebP files. Each placement has a unique source photograph; smaller `-640.webp` variants are supplied through srcset. `assets/image-inventory.json` maps each photograph to its page, name and descriptive alt text. `documentation/image-prompts.json` records the final prompt set. The favicon and logo mark were created as original SVG geometry.

Photographs were reviewed as a contact sheet for contextual relevance and visible defects. AI-generated photographs can still contain subtle anatomical or environmental inaccuracies. Review any image for your intended production use.
